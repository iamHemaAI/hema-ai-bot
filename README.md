# Hema AI Bot

Telegram-бот, который помогает пользователям вводить результаты анализа крови и получать PDF-отчёт с ИИ-разбором.

## Что делает

- Регистрация пользователей в боте.
- Пошаговый квиз для ввода 10 показателей крови.
- Автоматическая отправка данных в сервис [blood_report_agent](../blood_report_agent) для анализа.
- Получение и отправка пользователю PDF-отчёта прямо в чат.

## Стек

- Go 1.26+
- Telegram Bot API ([telebot](https://github.com/tucnak/telebot))
- SQLite — база данных пользователей и анализов
- [Goose](https://github.com/pressly/goose) — миграции БД

## Быстрый старт

1. Скопируй `.env.example` в `.env` и заполни:
   - `TG_TOKEN` — токен Telegram-бота от [@BotFather](https://t.me/BotFather)
   - `BLOOD_REPORT_URL` — адрес запущенного `blood_report_agent`
2. Примени миграции базы данных:
   ```bash
   task migrate
   ```
3. Запусти локально с авто-перезагрузкой:
   ```bash
   task run
   # или
   air -c .air.toml
   ```
4. Или через Docker:
   ```bash
   task up
   ```

## Как пользоваться ботом

1. Найди бота в Telegram и нажми **Start**.
2. Бот зарегистрирует тебя и покажет кнопку **Анализировать**.
3. Нажми кнопку — бот начнёт пошаговый опрос:
   - Гемоглобин
   - Эритроциты
   - Лейкоциты
   - Тромбоциты
   - И ещё 6 показателей...
4. После последнего вопроса бот отправит данные на анализ и пришлёт PDF-отчёт.

## Структура проекта

```
cmd/bot/           — точка входа
internal/
  app/             — инициализация приложения и DI
  config/          — загрузка конфигурации
  domain/          — бизнес-логика, модели, квиз
  repository/      — работа с SQLite
  services/        — сервисный слой (пользователи, анализы)
  tgbot/           — обработчики Telegram
migrations/        — SQL-миграции Goose
```

## Полезные команды (Task)

| Команда | Описание |
|---------|----------|
| `task run` | Запуск локально с авто-перезагрузкой (air) |
| `task build` | Собрать бинарник |
| `task up` | Запуск в Docker |
| `task down` | Остановить Docker-контейнеры |
| `task logs` | Посмотреть логи |
| `task migrate` | Применить миграции БД |
| `task migrate-down` | Откатить последнюю миграцию |

## Связь с другим сервисом

Бот зависит от сервиса `blood_report_agent`. Перед запуском убедись, что он доступен по адресу, указанному в `BLOOD_REPORT_URL`.
